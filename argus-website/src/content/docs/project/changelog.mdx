This page is a summary. The repository's `CHANGELOG.md` is the authoritative

to check when the two differ. Argus follows [Semantic Versioning](https://semver.org/).

## 0.2.0b2 â€” 2026-11-16 (audit remediation)

Tagged `v0.2.0b2` and published to PyPI as `argus-recovery` `0.2.0b2`. Headline changes:

- **Model dispatch.** A named model is pinned for every attempt. The cheap-first
  cascade applies only when no model is named and the provider has a documented
  ladder; this is reachable from the Python API only, because the CLI and MCP
  server always send the stored provider's model. No silent substitution; no fallback to a small local model on budget
  pressure.
- **Patch engine.** Tier 3 is now token-equal (no more similarity-based matches
  that could change an operator or name). Tier 1 needs a line/token boundary.
  Line endings, BOMs and encodings are preserved; undecodable files are refused.
  Truncated blocks apply nothing.
- **Workspace.** Copy snapshot is Git-tracked plus untracked-not-ignored files;
  `data/`, `build/`, `dist/` and similar are no longer dropped. Git worktree mode
  was removed.
- **Signed candidates.** HMAC-signed metadata; strict run IDs; per-run apply lock.
- **Cost safety.** Unpriced models are refused; budgets must be finite and
  positive; project policy files can only tighten limits.
- **MCP and gateway hardening, and documentation.** Workspace confinement, budget
  cap, removal of test-mode authentication bypasses; corrected commands and claims
  and a research status table.

## 0.2.0b1 â€” 2026-11-06

Pre-release. Distribution name `argus-recovery`; command `argus`.

- **Patch engine.** Tiers 1-5 (exact, whitespace-normalized, similarity-based
  Tier 3, experimental opt-in Tier 4 anchors, safe refusal) with an `ast.parse`
  gate on every candidate. Tier 3 was replaced in 0.2.0b2.
- **Runtime.** Temporary-copy workspace, bounded subprocess supervision with
  process-tree termination, and candidate artifacts under `.argus/runs/<run_id>/`
  applied atomically with hash checks.
- **Interfaces.** CLI, Textual TUI, FastMCP stdio server, provider presets, and an
  experimental gateway proxy (optional extras).
