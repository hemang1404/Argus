Argus is an engineering project. Contributions are judged on correctness,
reliability, security, reproducibility, and testability before style.

## Set up

```bash title="Shell"
git clone https://github.com/hemang1404/Argus.git
cd Argus
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\Activate.ps1
pip install -e ".[dev,tui,gateway]"
```

Run the offline suite before opening a pull request. It needs no network, API key
or model access:

```bash title="Shell"
ARGUS_OFFLINE=1 pytest -q -m "not live_provider and not live_antigravity and not real_host and not tokenizer_download"
```

Tests must not touch your real keyring, `ARGUS_CONFIG_DIR` or the repository root;
use `tmp_path` and the fixtures in `tests/conftest.py`.

The full guide, covering the focused gates, lint, engineering standards, test
expectations, branch and commit conventions, and pull request review criteria, is
[`CONTRIBUTING.md`](https://github.com/hemang1404/Argus/blob/main/CONTRIBUTING.md)
in the repository. Documentation changes live in `argus-website/` and must be
verified against the implementation.

## Security reports

Do not open a public issue for a vulnerability. Use GitHub Security Advisories on
the repository with reproduction steps, affected components, and versions. See the [security model](/project/security-model/).

## Community

All participants are expected to follow the project's Code of Conduct. Be
precise, assume good faith, and keep discussion focused on the engineering
problem.
